# Mini CRM

A simple and interactive web application designed to manage customer information efficiently through an organized and user-friendly interface.

## Overview

Mini CRM is a web-based application developed to simplify customer record management. It provides an interface for managing customer information and demonstrates the implementation of a client-side web application using HTML, CSS, and JavaScript.

The project focuses on providing a clean interface and basic customer management functionality in a simple and accessible format.

## Key Features

### Customer Management

* Add customer information.
* View customer records.
* Update existing customer details.
* Delete customer records.
* Manage customer information through an organized interface.

### User Interface

* Clean and simple design.
* Responsive layout.
* Interactive elements for managing customer records.
* Easy-to-use interface.

### Data Management

* Organizes customer information efficiently.
* Provides dynamic interaction using JavaScript.
* Updates the displayed information based on user actions.
